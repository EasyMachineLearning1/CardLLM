# CardsService — генератор карточек приборов (FastAPI + GigaChat)

Сервис принимает данные о товаре (веб-форма или JSON), передаёт их в GigaChat через API и возвращает готовый черновик карточки в формате **JSON**, **Markdown** или **текста** — удобном для копирования.

---

## 📝 Инструкция для контент-менеджера (как работать каждый день)

Вам не нужно знать программирование. Всё делается в три действия:

### 1. Запустить программу

Двойным щелчком откройте файл **`start.bat`** в папке программы.
Появится чёрное окно — **не закрывайте его**, пока работаете. Через пару секунд
сам откроется браузер со страницей генератора (адрес: http://localhost:8000).

### 2. Заполнить форму и создать карточку

На странице четыре шага:

1. **Что за прибор** — название и производитель (обязательно).
2. **Характеристики** — пары «параметр → значение», например «класс точности → 1,5». Лишние строки можно удалить крестиком.
3. **Описание прибора** — вставьте описание от производителя, если есть (не обязательно).
4. Нажмите большую кнопку **«✨ Создать карточку»** и подождите 10–30 секунд.

Готовая карточка появится внизу страницы:
- **«📋 Копировать текст»** — карточка попадёт в буфер обмена;
- **«⬇ Скачать файлом»** — сохранится файлом `.md` / `.txt` / `.json`;
- **«🧹 Очистить всё и начать заново»** — сброс формы для нового прибора.

Если программа напишет «⚠ Не хватает данных» — добавьте перечисленные сведения и сгенерируйте карточку заново: карточка станет лучше.

### 3. Закрыть программу

По окончании работы просто закройте чёрное окно `start.bat`.

### Если что-то не работает

- **«Нет связи с программой»** — значит, окно `start.bat` закрыто. Откройте его заново.
- **«Не удалось получить ответ от нейросети»** — подождите минуту и нажмите кнопку ещё раз.
- Остальные проблемы — напишите ИТ-специалисту и приложите текст ошибки с экрана.

## Что возвращает сервис

Для каждого товара формируется:
1. **SEO-заголовок** — до 70 символов.
2. **SEO-описание** — 800–1 200 символов.
3. **Структурированный список ключевых характеристик**.
4. **3–5 поисковых запросов** для оптимизации страницы.
5. **Краткий commercial-блок** для менеджера: кому подходит прибор и какие задачи решает.

Если входных данных недостаточно, сервис сообщает об этом: в ответе есть поле `missing_fields` (какие данные отсутствуют или требуют уточнения) и `warnings` (замечания к требованиям формата, например, слишком короткое SEO-описание).

## Архитектура

```
Веб-форма (static/index.html)
        │  POST /api/generate  { device, output_format: json|markdown|text }
        ▼
FastAPI (app/main.py) ── валидация (app/models/schemas.py)
        │
        ├── prompt_builder (app/services/prompt_builder.py) — сборка промпта + подсказки о нехватке данных
        ├── gigachat_client (app/services/gigachat_client.py) — официальный SDK
        │        ▼
        │    LLM GigaChat (строгий JSON по схеме карточки)
        │        ▼
        └── formatter (app/services/formatter.py) — парсинг карточки и рендер JSON/Markdown/текст
        ▼
Ответ: { name, output_format, content, missing_fields, warnings, model }
```

## Быстрый старт

### 1. Ключ GigaChat

Получите ключ авторизации в [GigaChat API](https://developers.sber.ru/gigachat) (base64 от `client_id:client_secret`).

### 2. Настройка окружения

Скопируйте шаблон переменных окружения:

```bash
copy .env.example .env  
```

и заполните `GIGACHAT_CREDENTIALS`.

### 3. Запуск

#### Вариант A — через [uv](https://docs.astral.sh/uv/) (рекомендуется)

```bash
# установка uv, если ещё нет:
# powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

uv sync
uv run uvicorn app.main:app --reload
```

`uv run` сам использует виртуальное окружение проекта — активировать его вручную не нужно.

#### Вариант B — классический venv + pip

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/macOS
pip install -r requirements.txt

python -m app.main
# или: uvicorn app.main:app --reload
```

- Веб-форма: http://localhost:8000/
- Swagger UI: http://localhost:8000/docs

## API

### `POST /api/generate`

```json
{
  "device": {
    "name": "Манометр показывающий DM 02",
    "manufacturer": "Манотомь",
    "specs": {
      "диапазон измерений": "0–1,6 МПа",
      "класс точности": "1,5",
      "присоединение": "G1/2",
      "диаметр корпуса": "100 мм"
    },
    "description": "Прибор предназначен для измерения избыточного давления..."
  },
  "output_format": "json"
}
```

Ответ:

```json
{
  "name": "Манометр показывающий DM 02",
  "output_format": "json",
  "content": "{ ...готовая карточка... }",
  "missing_fields": ["температура рабочей среды — требует уточнения"],
  "warnings": ["SEO-описание короче минимума: 740 симв. (требуется 800–1200)"],
  "model": "GigaChat"
}
```

Структура карточки внутри `content` (JSON-формат):

```json
{
  "seo_title": "Манометр показывающий DM 02 — измерение избыточного давления",
  "seo_description": "(текст 800–1200 символов)...",
  "specs": [{ "key": "диапазон измерений", "value": "0–1,6 МПа" }],
  "search_queries": ["манометр dm 02 купить", "манометр показывающий", "манометр Манотомь цена"],
  "commercial_block": "(кому подходит и какие задачи решает)...",
  "missing_fields": []
}
```

### `GET /api/health` — healthcheck.

## Примечания

- Для B2B/Corp-ключей измените `GIGACHAT_SCOPE` в `.env`.
- Если используется НУЦ Минцифры, положите сертификат рядом и установите `GIGACHAT_VERIFY_SSL=true` (путь к сертификату задаётся в `GigaChat(...)` в [gigachat_client.py](app/services/gigachat_client.py)).
- Форматтер в [formatter.py](app/services/formatter.py) автоматически срезает ```-обёртки, извлекает JSON-объект из ответа модели и валидирует его по схеме карточки.
- Ограничения формата заданы константами в [schemas.py](app/models/schemas.py): заголовок ≤ 70 симв. (обрезается автоматически), описание 800–1 200 симв., 3–5 запросов (излишки срезаются).
